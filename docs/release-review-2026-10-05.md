# Ревью релиза Tracker — 5 октября 2026

Релиз включает прежнюю неопубликованную версию Honest Portfolio №24 и исправления полного ревью. Существующие покупки, продажи, заметки и структура трёх портфелей сохранены. CS2 и Sandbox используют только Steam Community Market в RUB, криптовалюты — DropsTab в USD.

## Существенные исправления

- Таблицы, карточки и детали содержат изменения единичной цены за 24 часа, 7 и 30 дней; общий обзор содержит изменения оценки. База должна быть реальным наблюдением до начала периода. Фактические даты и допустимое отставание базы показаны в пояснении.
- Сравнение суммы требует одинаковых остатков и покрытия. Даты отдельных котировок сохраняются; старое значение не становится новым наблюдением при частичном обновлении. Старые снимки без количества не дают недоказанную общую динамику.
- Графики получили дневной период; шкала недорогих токенов использует фактический диапазон. Текущая средняя покупка не переносится в прошлые снимки.
- История больше не ограничена последними 240 точками: частые снимки сохраняются за два дня, почасовые до недели, дневные до года, недельные старше.
- Источники проверяются перед использованием. Ошибки чтения GitHub отделены от ошибок Steam/DropsTab; предыдущие успешные данные и даты сохраняются. Публичное чтение использует raw CDN вместо REST API с низким анонимным лимитом.
- Обновление настроено на каждые 15 минут. При ограничении Steam запросы замедлены до четырёх секунд, самые старые котировки запрашиваются первыми; серия сетевых ошибок не блокирует остальные источники. Отсутствие новой цены не создаёт вымышленную точку.
- Неизвестные общие суммы показываются как неизвестные, а не ноль. Достоверность курса DropsTab и чисел проверяется; пропущенная дата сделки не превращается в 1970 год.
- Большая история передаётся gzip без потери наблюдений. Проверочный набор из 677 разнообразных снимков: 27 037 371 байт JSON сжаты до 1 281 515 байт и полностью восстановлены, ниже лимита Vercel. Steam ID ссылки на инвентарь передаётся только с авторизованными данными сервера.

## Ограничения

GitHub schedule может опаздывать и пропускать запуски, Steam может ограничивать частоту запросов. Расписание не гарантирует, что каждая цена всегда моложе 15 минут; фактические даты и ошибки видны в продукте. Страница проверяет публикацию каждые пять минут, raw CDN имеет собственный кеш.

Месячная и годовая история новых источников будет накапливаться. Отсутствующие котировки QA Team T-Shirt и неизвестные комиссии/даты не восстанавливаются догадками. Вход закрывает страницы и API, но публичный GitHub и исходные публичные портфели остаются публичными. Ограничение попыток входа хранится внутри одного процесса Vercel.
