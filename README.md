# Tracker — личный капитал

Приватный трекер CS2, Sandbox (Steam app 590830) и криптовалют. Главная содержит общую рублёвую оценку и сводную таблицу; `/cs2`, `/sandbox`, `/crypto` — отдельные портфели. Крипта и её сделки учитываются в USD; рублёвый эквивалент рассчитывается по явно указанному курсу оценки DropsTab.

Новое визуальное направление от 8 октября 2026: светлая аналитическая рабочая среда с зелёной навигацией и подробной статистикой каждого актива. Прежний дизайн отменён пользователем. Решение и критерии: [docs/design-direction-2026-10-08.md](docs/design-direction-2026-10-08.md).

Графики: день, неделя, месяц, год и весь доступный период, оси суммы/дат, просмотр значений и клавиатурная навигация. В таблицах, карточках и деталях показаны изменения единичной цены за 24 часа, 7 и 30 дней; в обзоре — изменения рыночной оценки. Сравнения используют реальные наблюдения до начала периода с допустимым отставанием базы 1 час / 2 часа / 24 часа соответственно; фактические даты доступны в пояснении. При старой цене, короткой истории или изменении остатков/покрытия выводится причина отсутствия сравнения. До подключения новых источников общей истории нет. Частичная оценка помечена; неизвестная цена и себестоимость остаются неизвестными. История операций доступна также для закрытых позиций.

## Данные

- `data/portfolio.json`: исходные 110 операций CS2, остаточная себестоимость FIFO; исходный импорт сохранён.
- `data/prices.json`, `data/history.json`, `data/live.json`: Steam Community Market, `appid=730`, `currency=5` (RUB); последние цены и реальные снимки CS2.
- `data/sandbox.json`: учёт 19 названий / 362 предметов по таблице и инвентарю; из Steam CSV отобраны 35 операций s&box: 28 покупок (105 шт., 21 421,84 ₽) и 7 продаж (15 шт., 10 115,37 ₽). История частичная; подтверждённые сделки заменяют совпадающие предварительные записи и не увеличивают табличный остаток. Lifejacket куплен за 677,35 ₽. Себестоимость и цена QA Team T-Shirt неизвестны.
- `data/crypto.json`: DropsTab, шесть открытых монет, закрытый PX и все 44 операции, исходные даты, цены и комиссии.
- `data/combined-history.json`: реальные общие снимки в RUB, покрытие, даты исходных котировок и курс каждого наблюдения.

Проверка источников и трактовка комиссий: [docs/source-verification.md](docs/source-verification.md). Год дат CSV — 2026, подтверждён пользователем. Время суток отсутствует и не подставляется; записи по таблице отмечены отдельно и имеют неизвестную дату. Комиссия в Steam CSV не выделена. Повторяющиеся строки сохранены: экспорт может повторять идентификаторы сгруппированных предметов.

Поиск, сортировка, категории, таблица/карточки, детали активов, график единицы, цели, заметки и закрепление доступны в интерфейсе. Личные настройки сохраняются в этом браузере; прежние CS2-заметки, цели и закрепления переносятся автоматически.

Импорт смешанной истории Steam (фильтр `App Id = 590830`, количество из `Item Name`, сумма из `Display Price`):

```sh
npm run import:sandbox -- "C:/path/market_history.csv" --year 2026
```

Повторный импорт того же файла не задваивает сделки. `Price in Cents` не используется: экспорт масштабирует суммы с десятичной запятой неодинаково. `accounting` хранит полный табличный учёт отдельно от частичной истории `trades`; обновление котировок сохраняет импорт. Старые снимки цены и себестоимости не переписываются. Для другого экспорта неизвестные позиции или противоречие с инвентарём требуют предварительной сверки.

## Доступ

Локально настроен указанный пользователем admin. Настройки хранятся только в игнорируемом `.env.local`: `AUTH_USERNAME`, `AUTH_PASSWORD_HASH`, `AUTH_SESSION_SECRET`. Пароль проверяется через scrypt, сессия подписана HMAC, cookie — HttpOnly / SameSite=Lax, Secure в production. Срок сессии 8 часов. POST входа/выхода проверяет полный Origin. Реальный размер тела входа ограничен 8 KiB; пять попыток за 15 минут резервируются до проверки пароля. Лимит хранится в памяти одного процесса.

Без настроенной авторизации приложение закрывает доступ. Страницы и API проверяют сессию на сервере; финансовые данные не импортируются клиентскими модулями. Действующие AUTH-настройки перенесены в sensitive production-переменные существующего проекта Vercel; `.env.local` в Git не попадает. Вход на сайте не меняет публичность исходного Steam/DropsTab-портфеля и файлов публичного GitHub-репозитория. Для полной приватности GitHub должен быть private, а серверу обновлений понадобится `GITHUB_DATA_TOKEN` с доступом к Contents.

## Обновление

GitHub workflow `.github/workflows/steam-prices.yml` настроен каждые 15 минут: `:07`, `:22`, `:37`, `:52` каждого часа UTC. Он обновляет Steam CS2 и Sandbox, DropsTab и общий снимок. Это целевое расписание: GitHub и источники могут задержаться или пропустить запуск. Источники обрабатываются независимо; при серии сетевых ошибок оставшиеся котировки сохраняют прежние даты. Страница читает обновлённые JSON через защищённый серверный API каждые 5 минут; при ошибке сохраняет последние успешные данные и явно показывает ошибку доставки отдельно от ошибки источника. Кнопка «Обновить» читает последние опубликованные снимки, а не запускает десятки Steam-запросов из браузера. Новая сборка Vercel для обновления цен не нужна.

Хранение истории: все наблюдения последних двух суток, почасовые до недели, дневные до года, недельные старше года. Снимки содержат реальные даты отдельных цен, количества и покрытие; значения до первого наблюдения не восстанавливаются из сделок. При отсутствии новых котировок новая точка не создаётся. Общая рублёвая динамика включает изменение курса оценки USD/RUB; график крипты и изменения её единичных цен остаются в USD.

Годовой архив единичных цен хранится отдельно в `data/price-history.json`; `npm run history:backfill` загружает публичную историю DropsTab в USD и проверяет доступность истории Steam в RUB. Источник и валюта проверяются до импорта. На 6 октября 2026 года архив DropsTab загружен для всех семи активов; публичный Steam Market возвращает `ecurrency=3` (EUR), даже при запросе `currency=5`, поэтому эти значения отклоняются. Для CS2 и Sandbox остаются реальные наблюдения трекера. Медианы продаж Steam не заменяют текущую цену предложения. Новейшая spot-цена DropsTab из архива используется, только если она свежее сохранённой котировки.

Мини-графики в таблицах и карточках открывают полный график предмета. В таблице цена одной единицы, средняя покупка, вложенная сумма и стоимость всех единиц показаны отдельно; сортировка доступна по цене, сумме позиции, вложениям, прибыли, доходности, количеству, названию и изменениям цены, в обе стороны. Неизвестные значения всегда внизу; закреплённые активы первыми. Денежная сортировка общего обзора использует текущий курс USD/RUB. Линия вложений на графике включается отдельно, чтобы она не скрывала небольшие колебания рыночной стоимости.

Годовой график криптовалют «Динамика текущего состава» — исторические цены × сегодняшние остатки. Он подписан отдельно от фактических наблюдений портфеля и не восстанавливает прошлые покупки или количества. Используются только дни, в которых есть реальные цены всех открытых криптопозиций; отсутствующие дни не заполняются.

```sh
npm run prices:update
npm run extras:update
npm run history:record
```

После изменений кода выполняются `npm run check`, коммит, push и deployment существующего проекта Vercel. Файлы `.env.local` и `.local/` исключены из Git. Публикация цен проверяется по успешному GitHub Actions run и датам котировок в `/api/portfolio`, а не только по наличию расписания.

Production: [tracker-myth-projects.vercel.app](https://tracker-myth-projects.vercel.app/). Проверки опубликованного релиза и ограничения: [ревью от 5 октября 2026](docs/release-review-2026-10-05.md).

## Hindsight

Используется существующий локальный Hindsight без новых зависимостей приложения. Проект включён в opt-in и закреплён за отдельным банком `coding-agent::treker`. Существующие Codex hooks запускают демон и сохраняют контекст работы. Авторизация фоновой модели остаётся в отдельном каталоге Hindsight.

Windows Startup: `Tracker Hindsight.vbs` вызывает `scripts/hindsight-start.mjs` без видимого окна. Команда проверяет здоровье сервиса и не создаёт второй демон. Проверка: `http://127.0.0.1:9077/health`. Ручной запуск: `npm run hindsight:start`. Конфигурация Hindsight скопирована в резервный файл перед изменением; настройки других проектов сохранены.

## Локальная работа и проверки

```sh
npm ci
npm run dev -- -p 3000
npm run dev:stop
npm run check
```

Dev-сервер запускается только через указанный npm script. Перед повторным запуском проверяется порт 3000; для остановки используется `dev:stop`. `check` выполняет все тесты и production build.
