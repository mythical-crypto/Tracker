# Tracker

Публичное портфолио предметов Counter-Strike 2. Все цены берутся только из **Steam Community Market** в рублях (`appid=730`, `currency=5`). Для оценки используется минимальная текущая цена объявления. Это ориентир до комиссии Steam, а не гарантированная цена продажи.

## Данные

- `data/portfolio.json` — 110 операций из семи предоставленных CSV: 48 открытых и 2 закрытые позиции. Цены покупок в выгрузке заданы в копейках; себестоимость оставшихся предметов рассчитывается методом FIFO.
- `data/prices.json` — последняя успешная цена Steam и время её получения для каждого предмета, а также изображения из Steam.
- `data/history.json` — реальные снимки оценки портфеля и цены каждого предмета. Графики появляются после двух полных снимков; исторические цены до запуска Tracker не выдумываются.
- `data/live.json` — единый снимок для сайта, читаемый через GitHub Contents API.

На странице есть поиск, сортировка, категории, табличный и плиточный виды, общий график и график в карточке каждого предмета. Заметки, целевые цены, закрепление предметов и тема оформления сохраняются в `localStorage` конкретного браузера и не синхронизируются между устройствами.

## Обновление

GitHub Actions запускает `node scripts/update-prices.mjs` в `:13` и `:43` каждого часа. Скрипт опрашивает Steam последовательно с паузами, сохраняет успешно полученные цены, а при сбое оставляет последнюю доступную цену и её дату. Страница на Vercel при открытии и затем раз в 5 минут читает `data/live.json` через GitHub Contents API; пересборка сайта для обновления цен не нужна. Если GitHub временно недоступен, остаются данные, встроенные при последней сборке. Расписание GitHub и ответы Steam могут задерживаться, поэтому интервал **целевой, не гарантированный**. Workflow не устанавливает зависимости, не использует кэш и не загружает артефакты в хранилище GitHub Actions.

## Локально

```bash
npm ci
npm run dev -- -p 3000
```

Для остановки локального сервера: `npm run dev:stop`. Для проверки: `npm run check`. Для ручного обновления цен: `npm run prices:update`.

Исходные CSV находятся вне репозитория. Если состав портфеля изменится, импортируйте новые выгрузки командой `node scripts/import-csv.mjs <каталог-с-CSV>`, затем обновите цены и добавьте картинки командой `node scripts/update-prices.mjs --icons`.
